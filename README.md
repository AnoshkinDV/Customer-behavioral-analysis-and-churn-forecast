# 🚗 Анализ поведения водителей и прогнозирование оттока в Uber

## 📊 О проекте
Комплексный проект по анализу данных и построению предиктивных моделей для решения бизнес-задачи удержания водителей в такси-сервисе. Проект демонстрирует навыки работы с реальными данными, применение статистических методов для принятия data-driven решений.

## 🎯 Ключевые достижения
- Выявление ключевых факторов, влияющих на отток водителей
- Сегментация водителей по различным параметрам
- Разработка системы раннего предупреждения оттока

## 💡 Основные результаты анализа

### 1. Факторный анализ
- Выявлены ключевые предикторы оттока:
  - Время с последней поездки (более 30 дней)
  - Тип используемого устройства (iPhone/Android)
  - Географическая локация (город)
- Проведена сегментация водителей по:
  - Рейтингу водителя
  - Количеству поездок
  - Средней оценке поездок

### 2. Статистическая проверка гипотез
Применены продвинутые статистические методы:
- Chi-square тест для анализа связи между:
  - Оттоком и типом устройства
  - Оттоком и городом
- Mann–Whitney U тест для сравнения групп
- Kruskal–Wallis тест для множественного сравнения

### 3. Анализ поведения водителей
- Исследование паттернов активности
- Анализ рейтингов и оценок
- Изучение влияния различных факторов на отток

## 🛠 Технический стек
- **Языки программирования:** Python
- **Анализ данных:** Pandas, NumPy
- **Статистика:** SciPy, Statsmodels
- **Машинное обучение:** Scikit-learn
- **Визуализация:** Matplotlib, Seaborn
- **Среда разработки:** Jupyter Notebook

## 📈 Структура проекта
- `churn_on_taxi.ipynb` - Jupyter notebook с полным анализом:
  - Предобработка и очистка данных
  - EDA и визуализация
  - Статистический анализ
  - Построение и валидация моделей
- `churn.csv` - Датасет с данными о водителях
