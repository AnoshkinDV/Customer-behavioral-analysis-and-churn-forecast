# 🚗 Анализ поведения водителей и прогнозирование оттока в Uber

## 📊 О проекте
Комплексный проект по анализу данных и построению предиктивных моделей для решения бизнес-задачи удержания водителей в такси-сервисе. Проект демонстрирует навыки работы с реальными данными, применение статистических методов и A/B-тестирования для принятия data-driven решений.

## 🎯 Ключевые достижения
- Снижение затрат на привлечение новых водителей через таргетирование групп риска
- Увеличение retention rate новых водителей
- Разработка системы раннего предупреждения оттока

## 💡 Основные результаты анализа

### 1. Факторный анализ
- Выявлены ключевые предикторы оттока:
  - Активность в первые 30 дней
  - Географическая локация (город)
  - Тип используемого устройства
- Проведена сегментация водителей с выделением групп риска

### 2. Статистическая проверка гипотез
Применены продвинутые статистические методы:
- Chi-square тест для категориальных переменных
- Mann–Whitney U тест для сравнения групп
- Kruskal–Wallis тест для множественного сравнения

### 3. A/B-тестирование
- Разработаны и протестированы продуктовые гипотезы
- Проведена оценка эффективности предложенных изменений
- Подтверждена значимость одной из гипотез по улучшению retention

## 🛠 Технический стек
- **Языки программирования:** Python
- **Анализ данных:** Pandas, NumPy
- **Статистика:** SciPy, Statsmodels
- **Машинное обучение:** Scikit-learn
- **Визуализация:** Matplotlib, Seaborn
- **Среда разработки:** Jupyter Notebook

## 📈 Структура проекта
- `churn_on_taxi.ipynb` - Jupyter notebook с полным анализом:
  - Предобработка и очистка данных
  - EDA и визуализация
  - Статистический анализ
  - Построение и валидация моделей
  - A/B-тест результаты
- `churn.csv` - Датасет с данными о водителях
